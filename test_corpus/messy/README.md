# messy — неполные и шумные материалы

Проекты с намеренно плохими входами: пустые файлы, один слайд, только `description.txt`, конфликтующие источники.

Структура как в `golden/`, но smoke по умолчанию **не** сканирует `messy/` (только `golden/`).

Добавляйте кейсы для ручной отладки и будущих негативных тестов.
