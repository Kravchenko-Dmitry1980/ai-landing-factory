# Быстрый старт для оператора

Краткая инструкция без OCR, моделей и сложной настройки.

## Как запустить

1. Установите **Python 3.12+** и **Node.js 20+**.
2. Склонируйте репозиторий.
3. В PowerShell из папки проекта:

```powershell
.\run.ps1
```

4. Откройте в браузере адрес из консоли (обычно `http://localhost:3000`).

Остановка: `.\scripts\stop_dev.ps1`

## Как загрузить документы

1. На главной странице загрузите файлы: **PPTX, DOCX, TXT или PDF**.
2. Лучший результат — **комплект**: презентация + текстовый документ (DOCX/TXT) с командой и описанием.
3. Дождитесь сборки ленда и перейдите в редактор.

## Как получить ленд

Система собирает структуру из текстового слоя документов. Проверьте блоки: название, суть, модули, команда, стек, результаты.

## Если что-то не подтянулось

- Откройте **редактор** и поправьте секции вручную.
- Для команды: кнопка «Редактировать текстом» — вставьте ФИО и роли списком.
- Если слайды только с картинками текста — загрузите **DOCX/TXT** или допишите блоки сами.
- **Не нужно** ставить Tesseract, EasyOCR, PaddleOCR или локальные LLM для обычной работы.

## Экспорт HTML

В редакторе или превью выберите экспорт / открытие публичной HTML-версии (стиль `university_platform` и др., если доступен в UI).

Экспорт **не блокируется**, если какое-то поле слабое или пустое — сначала допишите в редакторе.

## Не надо для обычного режима

- Ollama, LM Studio, vLLM
- CUDA / GPU
- Docker (если вы уже запускаете без него)
- Скрипты `setup_ocr_runtime.ps1` и benchmark OCR

Это только для режима **advanced/research** (разработчики).
